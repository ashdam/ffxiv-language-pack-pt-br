# Language pack em português do Brasil para FFXIV (não oficial)

Tradução para o português do Brasil dos textos de Final Fantasy XIV para o plugin do Dalamud
**Gubal Library**. Não modifica os arquivos originais do jogo.

Instalação e estado da tradução:
**[eorzea-in-spanish.ashdam.workers.dev/pt-br/](https://eorzea-in-spanish.ashdam.workers.dev/pt-br/)**

Como colaborar com a tradução, passo a passo:
**[eorzea-in-spanish.ashdam.workers.dev/localize/pt-br.html](https://eorzea-in-spanish.ashdam.workers.dev/localize/pt-br.html)**

Uma linha mal traduzida: https://github.com/ashdam/ffxiv-language-pack-pt-br/issues
